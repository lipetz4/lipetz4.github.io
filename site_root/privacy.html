2. Какие данные мы получаем

  • Игра не требует регистрации и не запрашивает имя, телефон, e-mail, контакты, геолокацию, фото или микрофон.
  • Таблица рекордов (RuStore-версия). Если вы участвуете в рейтинге, на сервер Разработчика передаются случайный анонимный идентификатор устройства, созданный Игрой (не связан с вашей личностью и рекламным ID), выбранный вами никнейм и игровые очки. Эти данные используются только для показа рейтинга игроков. Не указывайте в никнейме персональные данные.
  • Технические журналы сервера (IP-адрес, время запроса) могут временно храниться для защиты от злоупотреблений и не используются для идентификации.

3. Игровой прогресс

В RuStore-версии прогресс (уровень, монеты, кристаллы, грядки, наряды, настройки) хранится на вашем устройстве; при удалении приложения он удаляется. В версии для Яндекс Игр прогресс может сохраняться в облаке через Yandex Games SDK (облачные сохранения в вашем аккаунте Яндекса) и в хранилище браузера; таблицы рекордов в этой версии ведёт платформа Яндекс Игры.

4. Реклама

В Игре показывается реклама Рекламной сети Яндекса (Yandex Mobile Ads SDK в Android-версии, Yandex Games SDK в веб-версии): видео за награду — только по вашему нажатию; межэкранная реклама — не чаще одного раза в несколько минут. Для показа и учёта рекламы SDK Яндекса самостоятельно получает технические данные устройства (рекламный идентификатор, IP-адрес, модель устройства, версию ОС, язык, сведения о показах). Эти данные обрабатывает ООО «ЯНДЕКС» по своей политике: yandex.ru/legal/confidential, yandex.ru/legal/mobileads_sdk_agreement. Разработчик эти данные не получает. Персонализацию рекламы можно ограничить в настройках Android («Конфиденциальность → Реклама»).

5. Покупки

Внутриигровые покупки (если доступны) проводятся платформой — RuStore или Яндекс Игры. Разработчик не получает и не хранит платёжные данные; он получает лишь подтверждение покупки для начисления товара.

6. Сторонние сервисы

  • RuStore (ООО «ВК») — распространение приложения: правила RuStore.
  • Яндекс Игры, Рекламная сеть Яндекса (ООО «ЯНДЕКС»).

7. Хранение и удаление

Данные рейтинга хранятся, пока Игра поддерживается. Чтобы удалить свой никнейм и результаты, напишите на serviceandreev@ya.ru — ответим в течение 10 рабочих дней. Локальные данные удаляются вместе с приложением или очисткой его данных.

8. Дети

Игра рассчитана на широкую аудиторию (6+) и не собирает сознательно персональные данные детей.
